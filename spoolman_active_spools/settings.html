🧵 Spoolman active spools

Display recently active filaments at a glance.

Connect your Spoolman instance, set the recent-activity window, customize the dashboard heading, and choose the spool details shown on your InkyPi display.

🔗

Connect Spoolman

Enter the base URL for the Spoolman instance that InkyPi can reach, including its protocol and port—for example, http://spoolman.local:7912.

🔌

Connection and activity

Point the plugin at Spoolman and define what counts as recently active.

Use the base URL only; do not append an API path.

Only spools active during this recent time window are included.

Optional title shown at the top of the dashboard.

📊

Display fields

Choose which spool details appear on the rendered display.
Color

Show the spool color information.

Material

Show the filament material type.

Brand

Show the filament brand or manufacturer.

Spool ID

Show each spool’s unique identifier.

Remaining grams

Show the estimated remaining filament weight.

Last used

Show when each spool was last active.

Location

Show the storage location or assigned place for each spool.
